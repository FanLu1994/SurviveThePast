# 《穿越失败》关卡设计总则

## 一、关卡目标与硬原则

每个关卡必须同时完成四件事：

1. 让玩家通过环境与人物线索判断年代和地域
2. 让玩家通过随身物品与人物关系推断身份
3. 让判断直接影响生存行动
4. 在结算阶段说明真实身份、历史背景、史实依据和剧情推演边界

所有关卡遵守以下硬原则：

- 玩家扮演有史料依据的普通人个体；可以基于群体史料整理匿名的典型个体，但不让玩家直接扮演抽象群体
- 每关围绕一个具体、紧迫、可在单局内解决的日常生存危机展开
- 年代、地域和身份判断必须服务于行动，不能退化为独立的历史知识问答
- 关卡至少提供三条有得有失的可行生路，不设置唯一标准答案
- 玩家不手填“存活方式”；系统根据实际选择、付出代价和结局自动归纳
- 通关前不直接公布关卡标题、年代、地点和身份，完整说明只在成功或部分成功后的结算和史料图鉴中展示
- 失败必须能够追溯到信息不足、判断偏差、资源不足或具体行动，不使用无预警随机死亡
- 史实、合理推演和剧情虚构必须明确分开，推演不能冒充确定史实

## 二、基础规模

单个完整关卡包包含：

- 12–18 个主要场景
- 30–50 个事件节点
- 4–6 种可随机身份
- 6–10 个结局
- 1 份时代内容圣经
- 1 份身份池档案
- 1 套史料来源清单

单局体验使用其中约 8–12 个主要场景，目标时长为 20–40 分钟。

## 三、关卡制作流程

### 1. 写清一句话关卡

正式查料和编写剧情前，先用一句话锁定：

> 某年某地，一个处于何种社会位置的人，因为哪条具体规则或现实困难，必须在多长时间内解决什么问题。

一句话关卡必须包含：

- 精确年份或允许的最小年份范围
- 具体地点和玩家可活动区域
- 普通人的社会位置
- 可感知的时间压力
- 不处理就会发生的现实后果

“在乱世活下去”“见证时代变化”等范围过大的目标不能进入制作阶段。危机应优先来自食宿、谋生、伤病、治安、交通、债务、征役、户籍或凭证、人情担保、礼法和地方规则等普通人会实际遇到的问题。

### 2. 建立史料底稿

先查清与核心危机直接有关的制度和生活事实，再从史料中提炼身份、线索与行动，不先写剧情再为结论补出处。

每项关键事实应由至少两项相互独立的资料交叉核对。存在可核验的一手材料时必须优先采用，并使用现代学术研究解释、校正或补充：

- A 级：能够直接反映该论点所涉年代、地点或人群的同时代文书、档案、法令、账簿、书信、日记、报刊或实物记录
- B 级：对原始材料进行整理或论证的正式学术专著、论文、资料汇编和校注史籍
- C 级：博物馆、档案馆、图书馆、高校、可靠地方志数据库发布的说明
- D 级：可靠科普和通俗历史内容，只能用于定位线索，不能单独支撑关键设定

资料等级由它与当前论点的关系决定，不能只按载体判断。同一份报刊对当时价格可以是一手记录，对更早年代的转述则不是一手证据。

无法取得适用的 A 级材料时，必须记录缺失或不采用的原因，并由至少两项相互独立的 B 级研究交叉支持。原始材料无法直接证明普通人生活细节时，由研究推导出的内容必须标为合理推演。

### 3. 制作身份池

每关准备 4–6 个随机隐藏身份。身份可以是匿名的典型个体，但不能伪称为史料中确有其人的具体人物。

每种身份必须记录：

- 身份依据及关联史料
- 籍贯、归属地或依附关系
- 职业、生计和社会位置
- 可支配财物与正常生活水平
- 可进入地点和可接触人物
- 合理掌握的知识及不可能掌握的知识
- 应遵守的制度、礼仪和行为边界
- 与主要人物的既有关系
- 初始危险和被怀疑的原因
- 独有信息、独有行动和身份暴露条件

身份之间不能只存在数值差异。每个身份至少改变两项可用行动、行动代价、已知信息或人物态度；只替换称呼和背景文字不算有效身份差异。

每个随机身份至少拥有两条现实可行的生存路线，不能让某个身份在实际游玩中只剩唯一解。

### 4. 定义核心生存危机

核心危机必须同时具备：

- 明确时限
- 可理解的现实后果
- 由当时制度、社会关系或生活条件形成的明确时代成因
- 至少三条可执行的生存路线

每条主要路线都要写明：

- 适用身份和所需前提
- 玩家要利用的证据、关系或资源
- 即时收益
- 必须付出的资源、关系或风险代价
- 中途修正机会
- 成功、部分成功和失败的落点

正确判断只能提高行动质量，不能自动保证生存。任何路线都不能因为作者偏好而成为无代价的最优解。

### 5. 编排场景、证据与结局

完成史料底稿、身份池和核心危机后，才进入场景编写。场景首先承担信息、关系、资源或风险变化，其次才承担气氛展示。只展示时代风貌、但不改变玩家理解或处境的场景应合并或删除。

## 四、关卡命名与剧透隔离

关卡内部名称与玩家可见名称分开处理：

- 内部文件名、内容编号和制作标题可以保留准确年代与地点，便于维护和审校
- 玩家通关前只看到关卡序号和“未知时空”等中性称呼
- 玩家可见标题不能包含朝代、年号、年份、地点、知名人物、标志性事件或能够直接锁定答案的器物
- 选关页和游玩页在通关前不得显示年代、年份、地域等内部元数据
- 前一关结算只能提示“下一关已开放”，不能提前显示下一关真实标题
- 未解锁史料不得显示资料标题、所属关卡或其他能够反推时代地点的信息
- 成功或部分成功通关后，才把中性称呼替换为真实关卡标题，并展示年代、地点和身份背景
- 失败结算可以解释玩家哪类判断或行动出了问题，但不能直接公布真实标题、完整年代、地点和身份答案

剧情中的人物言行、器物和环境仍可提供时代线索；需要玩家观察和交叉判断的线索不算剧透。系统标题、菜单元数据和未解锁内容直接给出答案才属于剧透。

## 五、关卡结构

### 1. 摸清处境

- 单局通常经历 1–2 个主要场景
- 不直接显示年代、地点和身份
- 首个场景提供至少三类可观察线索
- 至少一条线索可以被现代常识合理误读
- 建立迫使玩家尽快行动的短期危机
- 让玩家知道眼下缺什么，但不立即说明完整原因

### 2. 建立落脚点

- 单局通常经历 2–3 个主要场景
- 玩家通过观察、交谈、劳动和交易补充证据
- 逐步取得住处、生计、关系、凭证或通行资格
- 不同身份看到的线索和可用选项不同
- 重要人物给出的信息受其立场、利益和认知限制
- 至少提供一次修正早期错误判断的机会

### 3. 危机升级

- 单局通常经历 3–4 个主要场景
- 让早期判断开始改变可用行动和人物态度
- 体力、伤病、财物和暴露度共同限制路线
- 旧选择的代价必须再次出现，不能只结算一次数值
- 玩家应在严重后果前获得至少一次可识别的风险反馈
- 失败应能追溯到具体判断或行动

### 4. 收束求生

- 单局通常经历 2–3 个主要场景
- 玩家使用已获得的证据、关系和资源完成一条生路
- 关卡目标必须在单局内得到明确结果
- 主要人物关系和持续后果需要结算
- 不强制所有身份进入同一个结局
- 结算解释关键线索、误判、真实身份和史料依据

单局四个阶段合计经历约 8–12 个主要场景；关卡包计入不同身份与路线可选场景后，内容总量仍须达到 12–18 个主要场景。

## 六、线索与证据设计

### 1. 生活细节优先

每个关卡应覆盖以下类别中的至少六类：

- 语言和称谓
- 文字与文书
- 服饰与发式
- 货币、物价与交易
- 饮食与器物
- 劳动与谋生方式
- 城市、乡村与建筑空间
- 官制、法律与办事程序
- 交通与通信
- 社会关系、习俗与禁忌

线索应优先表现普通人当时如何吃饭、找住处、挣钱、办事、出行、求助和规避危险，避免只堆放名人、年号和重大事件。

### 2. 证据关系

证据类型与 [`玩法设计.md`](../玩法设计.md) 保持一致：

- 强证据：来源可靠，对判断具有较强约束力
- 弱证据：能够支持某种判断，但存在多种解释
- 误导信息：来自不可靠人物、错误认知或玩家的现代偏见

设计约束：

- 每个核心结论至少需要两条相互独立的证据支持
- 两条证据不能只是同一消息被不同人物重复转述
- 强证据不能全部集中在开场
- 弱证据必须存在多种合理解释
- 误导信息必须符合提供者的立场或时代认知
- 误导信息必须能从来源可靠性、矛盾细节或后续证据中识别
- 不能依赖玩家记忆冷门年份才能继续游戏
- 关键证据必须关联来源编号，剧情装饰性细节也要标记内容类型

### 3. 反馈方式

- 玩家判断错误时，先通过称谓不当、程序受阻、价格异常、人物戒备等自然反馈提示
- 严重后果应建立在玩家已经见过但忽略的风险信号上
- 不在主线中弹出“答案错误”或现代历史讲解
- 玩家获得新证据后可以修正假设，但此前行动产生的后果不撤销

## 七、选择与分支设计

采用局部分叉、关键节点汇合：

- 关键选择改变后续资源、人物态度、可用路线或结局
- 每个关键选择通常提供 2–4 个真实可行的行动
- 行动文案使用玩家当下能理解的目标，不提前泄露隐藏身份或系统判定
- 小型分支在完成信息、关系或代价变化后回到关键节点
- 身份差异优先通过选项、信息和代价体现
- 同一结果不能只替换少量文字后伪装成不同分支
- 每条主要路线必须允许玩家理解成功条件和失败原因
- 不显示传统百分比成功率，让玩家根据剧情语境、人物反应和证据评估风险

每个关键行动在内容设计阶段必须记录：

- 行动的直接目的
- 所需身份、证据、关系或状态
- 即时资源变化
- 后续风险和持续影响
- 所属求生策略
- 用于结算复盘的预先编写文案

## 八、存活方式自动归纳

“存活方式”指玩家在本局实际采用的求生路径，不等同于年代、地域和身份假设。玩家可以继续提交和修正推理假设（历史时期、所处地域、自身职业或阶层、与关键人物的关系、当前危机），但不需要另行填写自己采用了什么存活方式。

### 1. 归纳依据

系统只根据以下已发生事实归纳：

- 玩家在关键节点选择的行动
- 行动实际消耗的体力、财物和人物关系，以及造成的伤病或暴露度变化
- 玩家承担或避开的暴露风险
- 最终解决核心危机的决定性条件
- 结局中真正保留下来的结果

普通浏览、重复点击和没有持续影响的小选择不参与归纳，避免把点击次数误当成策略。

### 2. 策略标记

关卡作者从项目统一的策略词表中为关键行动选择标签。词表可以包含依靠关系、遵循制度、交换资源、劳动换取、隐瞒伪装、回避转移等普通人生存手段，但不能为单关随意创造同义标签。

每个标签必须对应具体行动和代价，不能使用“聪明”“勇敢”“善良”等性格评价代替生存策略。

### 3. 结算规则

- 对结局起最大作用的策略显示为主存活方式
- 次要但不可缺少的策略显示为辅助存活方式
- 没有明显主导策略时显示混合求生路径
- 结算列出真正起决定作用的 2–3 次行动
- 归纳结果使用作者预先审校的文案组合，运行时不使用 AI 自由生成
- 归纳只描述玩家做了什么、付出什么和为何奏效，不替玩家评价人格

## 九、结局结算

所有结局都进入结算。结局类型与 [`玩法设计.md`](../玩法设计.md) 一致：`success`（成功）、`partial`（部分成功）、`failure`（失败）。成功或部分成功视为通关，并按“如何活下来、自己是谁、为何处于这种环境、依据是什么”的顺序完整展示；失败不视为通关，只说明可追溯的失败原因和继续推理所需的方向，不公布完整答案。结算不把全部表现压缩为单一总分，并分项呈现生存结果、断代准确度、地域判断准确度、身份还原度、关键史实理解、主要误判及其后果、本局解锁史料。

### 1. 生存结果

- 说明成功、部分成功或失败后的现实处境
- 展示主存活方式、辅助存活方式和决定结果的关键行动
- 说明玩家付出的资源、关系和风险代价
- 说明仍未解决的后患，避免把部分成功写成圆满结局

### 2. 身份背景

成功或部分成功通关后，明确告知本局真实身份，并至少说明：

- 这种身份在当时通常是什么人
- 如何谋生和维持日常生活
- 处于怎样的社会位置
- 受谁管理、依附谁或需要谁担保
- 拥有哪些有限权利和现实限制
- 为什么本局某些行动可用、受限或容易暴露

身份揭示应回看 2–3 个已经出现的伏笔，使玩家理解自己原本可以如何判断。匿名身份应标为基于史料整理的典型个体，不虚构其为有确切传记的历史人物。

### 3. 历史背景

成功或部分成功通关后展示与本局直接相关的历史背景：

- 只解释与本关生存危机直接有关的制度、地方环境和社会变化
- 先用白话说明因果，再补充准确历史术语
- 区分当时普遍情况、本地区情况和特定年份变化
- 不把局部材料概括为全国常态
- 不用泛泛朝代史挤占与玩家本局经历直接相关的内容

### 4. 判断与误判复盘

每项关键判断按以下因果链说明：

> 玩家看到了什么 → 为什么容易这样理解 → 证据实际支持什么 → 该判断影响了哪个行动和结果。

- 重点列出 1–3 个真正改变路线的正确判断或误判
- 不只显示正确率或“回答错误”
- 误判必须解释其时代内的合理诱因
- 正确判断必须展示交叉证据链

失败结局必须说明造成失败的判断、资源或行动原因，不能让玩家死得不明不白；但只提示需要重新核对的证据方向，不公布真实年代、地点、身份及其关联史料。

### 5. 本局关联史料

成功或部分成功通关后，结算页直接展示支持本局身份背景、历史背景、关键判断和合理推演的关联史料，无论这些史料是否在此前解锁；首次解锁的资料另行标记为“本局新增”。史料图鉴长期保存全部已解锁内容，不能要求玩家必须跳转图鉴后才能看到本局依据。

每张史料卡记录：

- 资料标题
- 作者、编纂者或保存机构
- 成书、形成或出版年代
- 卷次、页码、档号或报刊日期
- 来源等级
- 对应本关的身份、制度、物价、称谓、器物或行动
- 白话摘要
- 该资料能支持的结论
- 该资料不能直接证明的内容
- 该资料所对应设定的内容类型：史实、合理推演或剧情虚构
- 可核验的稳定链接；没有稳定链接时保留完整出版信息

一手史料与现代研究分开显示。史料只支持背景、不能直接证明剧情细节时，必须明确写出推演过程和边界。

## 十、史实审校

每条历史性陈述记录：

- 来源编号
- 来源名称与等级
- 原始材料、出版信息和精确定位
- 支持的内容
- 不能推出的内容
- 内容类型：史实、合理推演或剧情虚构
- 初审人与审校状态
- 二次审校人及审校意见

涉及制度、物价、语言、服饰、地理、法律程序和社会身份的信息必须进行二次审校。审校不仅检查“有没有这种东西”，还要检查它在本关的年份、地点、身份和场景中是否合理。

## 十一、关卡验收

### 1. 内容验收

- 不看标题也能通过多条线索判断时代范围
- 核心危机具体、紧迫，并由时代环境造成
- 不同身份具有真实的路线差异
- 至少存在三条有代价的可行生路
- 错误判断会产生可理解的后果
- 正确判断不会自动保证生存
- 所有关键历史信息具有可定位来源
- 推演和虚构没有被写成确定史实

### 2. 玩法验收

- 所有关键结论均有至少两条独立证据
- 每次严重失败前均出现可识别的风险反馈
- 每项关键选择至少改变资源、关系、风险、路线或结局中的一项
- 身份差异不只表现为数值和称呼变化
- 存活方式能够从玩家实际行动自动归纳，无需玩家手填
- 通关前的选关、游玩、下一关提示和未解锁图鉴均不泄露年代与地点
- 所有结局均可到达
- 没有无法推进的剧情节点

### 3. 结算验收

- 通关后明确揭示真实身份及其生活背景
- 失败结算不显示真实关卡标题、完整年代、地点和身份答案
- 历史背景只讲解与本局因果直接相关的内容
- 关键史实理解能够对应本局出现的制度、物价、称谓或程序
- 关键行动、代价和存活方式能够互相对应
- 主要误判能够追溯到具体证据和后果
- 支持本局身份、背景和关键推演的关联史料在结算页直接展示，本局新增资料另有标记
- 每张史料卡均能说明它具体支持了什么

### 4. 一票否决项

出现以下任一问题时，关卡不得发布：

- 核心危机只能概括为“在这个时代活下去”
- 身份没有史料依据，或身份差异不改变玩法
- 只有一条正确生路，其他选择均为假分支
- 关键判断依赖单一线索
- 误导线索无法在结算中合理解释
- 选择与持续后果无关
- 存在无预警随机死亡
- 通关后不揭示真实身份
- 通关前的标题或元数据显示朝代、年份、地点或其他直接答案
- 历史背景与玩家本局经历没有直接关系
- 史料没有卷次、页码、日期、档号或完整出版信息等定位资料
- 合理推演被包装成确定史实

发布前必须进行人工完整通关验证，验证范围至少覆盖成功、部分成功、失败和不同身份路线。

## 十二、术语与玩法设计对照

本总则与 [`玩法设计.md`](../玩法设计.md) 共用以下术语，制作关卡时不得另造同义概念：

| 术语 | 含义 |
|------|------|
| 关卡包 | 独立历史关卡内容单元 |
| 证据 | 强证据、弱证据、误导信息三类线索，关联来源编号 |
| 假设 | 年代、地域、身份、关系、危机五字段，玩家可修正 |
| 身份 | 随机隐藏，影响可用选项、信息和代价 |
| 局内四状态 | 体力、伤病、财物、暴露度 |
| 生存行动 | 场景预设选项，玩家不自由输入行动文本 |
| 存活方式 | 系统根据关键行动自动归纳的求生路径，玩家不手填 |
| 结局 | success / partial / failure |
| 史料图鉴 | 局外解锁的 SourceRef 集合 |
| 内容类型 | historical（史实）/ inference（合理推演）/ fiction（剧情虚构） |
