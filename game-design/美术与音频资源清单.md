## 十、技术规格建议

### 图片

- 格式：优先 `webp`，备选 `png`
- 背景图：1920×1080（16:9），移动端可额外导出 1080×1920 竖版
- 立绘：高度约 1200px，透明背景 `png` / `webp`
- 体积：单张背景建议 < 300KB（webp 压缩后）

### 音频

- 格式：优先 `mp3`（兼容性），备选 `ogg`
- 背景音乐：128–192 kbps，循环无缝（首尾可接）
- 音效：44.1kHz，单段 < 3 秒
- 环境音：可循环，30–90 秒
