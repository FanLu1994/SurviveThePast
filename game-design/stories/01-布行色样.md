# 布行色样

## 一、状态

样板关。对应可玩内容：`src/content/levels/jiaqing-cloth/`（替换原第 1 关位）。

## 二、一句话关卡

嘉庆十一年秋，江南某县市镇布行，学徒在晒场弄丢客人标定色样的布角；须在掌柜申时点货对样前找回或补救，否则赔布、挨罚、可能被辞号。

## 三、内部制作信息（通关前不对玩家显示）

- 年份：1806（清嘉庆十一年）
- 地点：江南某县市镇（非省城），一家中等布行的晒场、号屋与邻近茶摊巷
- 不是：鸦片战争、太平天国、帝位更迭或任何战役现场

## 四、核心危机

- **缺什么**：客人留下的「色样布角」（一小片已标定深浅的布头，用于对染/对货）
- **时限**：申时掌柜回号点货；日影西斜，晒场要收绳
- **不处理的后果**：客人色样对不上，学徒按号规赔疋、记过；再犯可被辞出

## 五、身份池（隐藏，随机其一）

| id | 对外可感位置 | 独有手段 |
|----|--------------|----------|
| apprentice | 跟缸学手的学徒 | 记得色号深浅，可尝试口述补样 |
| yard_hand | 晒场杂工 | 熟悉风向与绳位，易找到刮落处 |
| runner | 跑街送样 | 认得邻号与常客，可求情暂压 |
| junior_clerk | 帮司账打杂的小写 | 能翻草账看色样编号与客名 |

## 六、生路（至少三条）

1. **找回**：沿晒绳、巷口、茶摊追查布角实物  
2. **补样**：凭记忆/草账描述，求染坊或熟练伙计重裁一小角应急  
3. **求情暂压**：托邻号或司账在掌柜前圆场，答应次日赔样（有代价）  
4. **买替**（辅）：用私房钱在市上买近似布头——可能色差翻车

## 七、场景序大纲

1. 晒场发现缺口 → 2. 沿绳翻找 / 问人 → 3. 茶摊闲话分流 → 4. 巷口或邻号 → 5. 号内柜台与草账 → 6. 抉择三线 → 7. 收束结局  

时间连续：午后 → 申时将至 → 点货。

## 八、主要人物（反复露面）

- **掌柜**：申时才回，严但讲号规  
- **司账老陈**：看草账、怕担责  
- **晒场老周**：杂工头，嫌学徒毛手毛脚  
- **茶摊妇**：卖粗茶，爱传闲话  
- **邻号染坊伙计**：能重裁色样，要工钱或人情

## 九、完整剧情

### 场景 1 · 晒场缺口

**标题**：晒绳空档  
**正文**：  
午后的晒场热气还未散尽。竹架上青白布疋垂着，绳上夹着写了炭笔编号的竹签。你负责看管的那一档里，客人留下的色样布角——本来夹在「三七」号签下——不见了。日影已经爬过墙根的半截碎缸。再拖下去，申时掌柜回号点货，这一档对不上样，按号规就要有人扛。

**线索**：竹签炭笔编号；晒场工序；市镇布行日常（非战场）。  
**选项**：  
- 立刻沿晒绳一根根翻 → 场景 2a  
- 先喊晒场老周问过 → 场景 2b  
- 先溜回号屋翻草账对编号 → 场景 5（小写更顺）

### 场景 2a · 沿绳翻找

**标题**：绳下泥印  
**正文**：  
你弯腰顺着绳下翻。碎布头、线头、一只干硬的草鞋印。东头风口的泥地上有一小撮新印，像有轻巧脚步拐进巷里。老周在远处收夹子，骂了一句「又给人捡了去」。

**选项**：  
- 追向巷口 → 场景 4  
- 去茶摊问有没有人拿着布头 → 场景 3  
- 认栽，回号里想别的法子 → 场景 5

### 场景 2b · 问老周

**标题**：老周的嘴  
**正文**：  
老周啐了口唾沫：「风大时，角布爱往巷口飘。茶摊那一带的娃娃也爱捡花布玩。你自己惹的，别扯上我。」他顿了顿又说：「掌柜申时准到。对不上，赔的是你月例。」

**选项**：  
- 去茶摊 → 场景 3  
- 去巷口 → 场景 4  
- 回号屋想补救 → 场景 5

### 场景 3 · 茶摊

**标题**：半碗粗茶  
**正文**：  
巷口茶摊支着旧布棚，铜壶咕嘟着。摊妇一边倒茶一边说：先前有个穿短打的后生捏着一小片布往染坊方向去；又有人说是她家侄儿捡了「花布」跑去东头。桌上搁着几枚制钱，茶钱论碗。

**线索**：制钱；市镇闲话；染坊方向。  
**误导可能**：有人扯「如今洋布便宜」——此地此刻未必买得到，也救不了色样编号。  
**选项**：  
- 追染坊方向 → 场景 4b 邻号染坊  
- 追东头娃娃传言 → 场景 4  
- 花点钱买摊妇细问 → 得更准方向，耗财物 → 再分流  
- 回号 → 场景 5

### 场景 4 · 巷口

**标题**：墙根布毛  
**正文**：  
巷口墙根粘着一线同色的布毛，像从更大一片上刮下的。再往前是泥地与鸡啄的痕。若你眼尖（晒场杂工更易），能在柴堆旁找回几乎完整的色样布角——边已经脏了，但炭笔痕还在。

**选项**：  
- 捡起布角，赶回晒场夹回 → 场景 6（持有色样）  
- 布角太脏，想洗净再回 → 耗时，险误点货  
- 没找到，转去染坊求补 → 场景 4b

### 场景 4b · 邻号染坊

**标题**：染坊求补  
**正文**：  
染坊里靛气扑鼻。伙计听你说完，敲着木桶：「没有原角，只能按你说的深浅重裁一小片。说得准，我帮你；说飘了，掌柜一眼就能看出来。工钱或者——你们司账老陈欠我一顿酒，看你讨不讨得到他的脸。」

**选项**：  
- 凭记忆描述深浅（学徒易成）→ 得补样 → 场景 6  
- 求司账出面（小写/跑街易成）→ 场景 5 再转  
- 掏私房钱买近似布 → 可能色差 → 场景 6 风险  
- 放弃，回号硬扛 → 场景 5

### 场景 5 · 号屋柜台

**标题**：草账与柜台  
**正文**：  
号屋柜台擦得发亮。司账老陈盯着草账：「三七号，客姓沈，色样注的是‘青，偏深，忌发红’。你把角弄丢，我可不能替你挨。掌柜的脚步……」外面日影更短。若你能看懂草账，这几字就是补样的骨头。

**线索**：草账行话；布行层级（掌柜/司账/学徒）。  
**选项**：  
- 抄下色注去染坊补样 → 4b  
- 求老陈在掌柜前暂压一晚（要你扣月例）→ 场景 6 求情线  
- 谎称色样尚在晒场未干（暴露风险）→ 场景 6 隐瞒线  
- 再出去找实物 → 3 或 4

### 场景 6 · 抉择（汇合）

**标题**：申时将至  
**正文**：  
晒场开始收绳。远处隐约有掌柜熟悉的咳嗽声。你手里或许有原角、或许有补样、或许只有一句求情的话、或许什么都没有。

**选项**：  
- 呈上找回/补得的色样，按号规对货 → 成功/部分（视色差）  
- 让司账开口暂压 → 部分成功（扣月例，过关）  
- 隐瞒丢失、胡乱拿别档布角充数 → 失败（识破）  
- 丢下一切离开布行 → 部分/失败（辞号逃生）

### 结局

| 结局 | 类型 | 要点 |
|------|------|------|
| 色样归位 | success | 原角或合格补样对上沈客之货 |
| 暂压记过 | partial | 今夜过关，月例被扣，号规记过 |
| 色差翻车 | failure | 近似布骗不过掌柜 |
| 隐瞒败露 | failure | 拿错档充数，当场辞号 |
| 力竭/吓破胆 | failure | 状态条触发 |

## 十、史料边界（结算用）

- **可支撑**：清代中后期市镇布行/染业中存在学徒与号规；色样/样布用于对色对货是行业常见做法；制钱为日常通货。  
- **推演**：具体「三七号」「沈客」与该县镇布局为剧情虚构。  
- **不能证明**：嘉庆十一年该镇某日的真实人事。
